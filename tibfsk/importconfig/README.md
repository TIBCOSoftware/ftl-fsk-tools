# tibftlimportconfig

Translates an Apache Kafka `server.properties` into the TIBCO FTL(R) Service for Kafka (FSK)
artifacts needed to run an FSK-enabled FTL Server cluster.

All documentation — installing the tool, twelve end-to-end scenarios, the full flag reference,
the output file details and the worked examples — is in
**[getting-started.md](getting-started.md)**.
